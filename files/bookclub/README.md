# Book Club 자료 폴더

이 폴더에는 **암호화된 파일만** 올립니다. 원본 PDF나 비밀번호는 절대 올리지 마세요.

## 자료 올리는 방법

1. 사이트에서 `bookclub-admin.html` 을 엽니다. (예: https://hojunglee.com/bookclub-admin.html)
2. 북클럽 비밀번호를 입력합니다.
3. 올릴 PDF 등을 고르고, 화면에 나오는 스니펫을 본문에 붙여 넣습니다.
4. 본문을 작성(또는 기존 `content.enc` 를 불러와 수정)합니다.
5. `암호화하기` 를 누르고 만들어진 `.enc` 파일을 내려받습니다.
6. 내려받은 파일을 이 폴더(`files/bookclub/`)에 업로드합니다. 같은 이름이면 덮어쓰기가 됩니다.

## 파일 구성

- `content.enc` — Book Club 페이지 본문 (암호화)
- `<파일이름>.enc` — 첨부 자료 (암호화). 예: `week1.pdf.enc`

## 암호화 방식

AES-256-GCM, 키는 PBKDF2-SHA256(310,000회)로 비밀번호에서 유도합니다.
복호화는 방문자 브라우저 안에서만 이루어지고, 비밀번호는 어디에도 전송·저장되지 않습니다.

비밀번호를 바꾸려면 본문과 모든 첨부 파일을 새 비밀번호로 다시 암호화해서 올려야 합니다.
