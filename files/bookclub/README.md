# Book Club 자료 폴더

이 폴더에는 **암호화된 파일만** 올립니다. 원본 PDF나 비밀번호는 절대 올리지 마세요.

## 구조

```
files/bookclub/
  seasons.json        시즌 ID 목록 (암호화하지 않음, 최신 시즌이 맨 앞)
  s1/content.enc      s1 시즌 본문 (암호화)
  s1/week1.pdf.enc    s1 시즌 첨부 자료 (암호화)
  s2/content.enc      s2 시즌 본문 ...
```

시즌마다 비밀번호가 다릅니다. 방문자가 비밀번호를 넣으면 페이지가 최신 시즌부터
차례로 복호화를 시도해서, 그 비밀번호로 열리는 시즌 하나를 보여줍니다.
지난 시즌 비밀번호로는 그 시즌 자료만 열리고 새 시즌은 열리지 않습니다.

## 자료 올리는 방법

1. `bookclub-admin.html` 을 엽니다. (예: https://hojunglee.com/bookclub-admin.html)
2. 현재 저장소의 `seasons.json` 을 불러옵니다. (첫 시즌이면 건너뜁니다.)
3. 시즌 ID와 그 시즌의 비밀번호를 입력합니다.
4. 올릴 PDF 등을 고르고, 화면에 나오는 스니펫을 본문에 붙여 넣습니다.
5. 본문을 작성하거나, 그 시즌의 기존 `content.enc` 를 불러와 수정합니다.
6. `암호화하기` 를 누르고 만들어진 파일을 내려받아, 화면에 표시된 경로로 업로드합니다.

기존 시즌을 수정할 때도 같은 시즌 ID와 같은 비밀번호를 쓰면 됩니다.
시즌을 닫으려면 그 시즌 폴더를 지우고 `seasons.json` 에서 ID를 빼면 됩니다.

## 암호화 방식

AES-256-GCM, 키는 PBKDF2-SHA256(310,000회)로 비밀번호에서 유도합니다.
복호화는 방문자 브라우저 안에서만 이루어지고, 비밀번호는 어디에도 전송·저장되지 않습니다.

한 시즌의 비밀번호를 바꾸려면 그 시즌의 본문과 첨부 파일을 모두 새 비밀번호로 다시
암호화해서 올려야 합니다.
